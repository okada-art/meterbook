# 走行メーター帳

iPhoneのホーム画面から使う、交通費（通勤・業務）の走行記録アプリです。
出発・到着メーターを入れると距離と金額を計算し、月ごとに集計します。

- 記録はそれぞれのiPhoneの中に保存されます（サーバーには送りません）
- 設定すれば、月の明細をGoogleスプレッドシートへ送れます
- 圏外でも開けます

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体 |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン |
| `sw.js` | 圏外でも開けるようにする仕組み |
| `apple-touch-icon.png` ほか | アイコン |

## 公開のしかた（GitHub Pages・無料）

1. https://github.com でアカウントを作ります（無料）。
2. 右上の「＋」→「New repository」。
   - Repository name：`meterbook`（英数字なら何でも可）
   - **Public** を選びます（無料プランのGitHub Pagesは公開リポジトリが条件です。アプリのプログラムが公開されるだけで、記録は各iPhoneの中にあるので外には出ません）
   - 「Create repository」
3. 作成後の画面で「uploading an existing file」をクリックし、このフォルダの**中身のファイルをすべて**ドラッグ＆ドロップして「Commit changes」。
4. リポジトリの「Settings」→ 左の「Pages」。
   - Source：「Deploy from a branch」
   - Branch：「main」／「/(root)」→「Save」
5. 1〜2分待つと、同じ画面に `https://（アカウント名）.github.io/meterbook/` と表示されます。これが配布用のURLです。

## 使う人への案内文（そのまま送れます）

> 交通費の走行記録アプリです。iPhoneの **Safari** で下のURLを開き、
> 画面下の共有ボタン（□に↑）→「ホーム画面に追加」を押してください。
> ホーム画面の「メーター帳」から起動し、最初に「設定」で氏名と通勤距離を入れてください。
> 記録はご自分のiPhoneの中に保存されます。**月に1回は「設定」→「バックアップ」→「書き出す」**でファイルに保存してください。
> URL：https://（アカウント名）.github.io/meterbook/

## スプレッドシート連携（任意）

アプリの「設定」→「スプレッドシート連携」→「送信先URLの作り方」に手順とコードがあります。

- 会社で1つのスプレッドシートを作り、そのURLを全員に配れば、全員の明細が「2026-08_氏名」のシート名で1か所に集まります。
- 送るたびにその月のシートを丸ごと上書きします。何度送っても重複しません。
- 送信先URLを知っている人は誰でもデータを書き込めます。社外には出さないでください。
- 送信の成否はアプリ側では確かめられません。初回はスプレッドシートにシートができたかを目で確認してください。

## 修正版の配り方

1. `index.html` を直したら、`sw.js` の `const CACHE = 'meterbook-v1';` の番号を上げます（v2、v3…）。`index.html` の `APP_VERSION` も合わせて上げます。
2. GitHubのリポジトリで「Add file」→「Upload files」から、直したファイルを上書きアップロードします。
3. 使う人は、アプリを一度閉じて開き直すと新しい版になります。記録は消えません。

## 注意

- 記録はiPhoneのSafariの保存領域にあります。**アプリ（ホーム画面のアイコン）を削除すると記録も消えます。** 消す前にバックアップしてください。
- 機種変更：旧iPhoneで「書き出す」→ファイルを新iPhoneへ（AirDrop・メール・iCloud Drive）→新iPhoneで「読み込む」。
- ホーム画面から開いたアプリと、Safariで開いたページは保存領域が別です。必ずホーム画面のアイコンから使ってください。
